# Agent-wire / LLM / log / telemetry

## Product backends

- **Product backends = separate repos.** Protocol repos may keep **noop** / **recording** / **stream** test sinks. Do **not** colocate OpenAI / OTLP / log4cl / vom / websocket-driver in the protocol repo. New LLM product backends use `llm-backend-*` (not `llm-protocol-*`). Native GGUF: [`llm-backend-vllm-cpp`](https://github.com/egao1980/llm-backend-vllm-cpp) (`stack-llm-vllm-cpp`). OpenAI wire is still [`llm-protocol-openai`](https://github.com/egao1980/llm-protocol-openai) (`stack-llm-openai`). Other examples: [`telemetry-backend-otlp`](https://github.com/egao1980/telemetry-backend-otlp), [`log-backend-log4cl`](https://github.com/egao1980/log-backend-log4cl), [`log-backend-vom`](https://github.com/egao1980/log-backend-vom), [`ws-backend-websocket-driver`](https://github.com/egao1980/ws-backend-websocket-driver), `http-backend-async`.

## Log ≠ telemetry

- **Logging ≠ telemetry.** [`log-protocol`](https://github.com/egao1980/log-protocol) (`stack-log`) **0.1.2** = logs + in-tree `stream-log-backend`. Default logger [`log-backend-log4cl`](https://github.com/egao1980/log-backend-log4cl) **0.1.1**; alternate [`log-backend-vom`](https://github.com/egao1980/log-backend-vom) **0.1.1**. [`telemetry-protocol`](https://github.com/egao1980/telemetry-protocol) (`stack-telemetry`) **0.1.0** = traces/spans + thin metrics. Correlate via `log-protocol:with-context` `:trace-id` / `:span-id`. Do **not** emit spans through the logger. OTLP/HTTP JSON = [`telemetry-backend-otlp`](https://github.com/egao1980/telemetry-backend-otlp).

## LLM / agent loop / capability

- **LLM protocol ≠ chat-completions blob.** [`llm-protocol`](https://github.com/egao1980/llm-protocol) (`stack-llm`): CLOS **turns + typed parts** (role on the turn; `llm-text-part` / `llm-tool-call-part` / `llm-tool-result-part` / `llm-thinking-part`). `generate` + `stream-generate`. **Responses-style** `respond` / `stream-respond` (`llm-item`: message / function-call / function-call-output / reasoning). Settings = `llm-settings`, not kwargs soup. Tools are descriptors, not executors. **Structured output** = `:output` a `schema-protocol` designator; JSON Schema emit via [`schema-protocol-json`](https://github.com/egao1980/schema-protocol-json); parsed object on `llm-response-output`. Optional `llm-protocol/schema`. **Not** PydanticAI `Agent` / output tools / retries. OpenAI wire is [`llm-protocol-openai`](https://github.com/egao1980/llm-protocol-openai) (`stack-llm-openai`) — **not** colocated. Native GGUF is [`llm-backend-vllm-cpp`](https://github.com/egao1980/llm-backend-vllm-cpp) (`stack-llm-vllm-cpp`). **Demiurge consumes** this — do not copy Demiurge `generate-text`/`generate-with-tools` or PydanticAI `ModelRequest`. **MCP sampling is not here** — `ai-agent-protocol/mcp`. Cookbook [`llm.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/llm.md) · [#195](https://github.com/egao1980/cl-stack/issues/195).
- **AI agent loop = `ai-agent-protocol`.** [`ai-agent-protocol`](https://github.com/egao1980/ai-agent-protocol) (`stack-ai-agent`) — async-first CLOS loop over `llm-protocol`. Primitive = callback + cancel token (http `send-async` shape). Sync `run-ai-agent` awaits a bound `event-protocol` loop. Do **not** steal `run-agent` — that's `ag-ui-protocol:run-agent`. Core has **zero** MCP/A2A/AG-UI deps. Nested agent in `:tools` = one peer tool (manager keeps control). `:handoffs` = specialist takes the run. `defagent` → `defclass`. MCP sampling (`create-message` → `generate`) is `ai-agent-protocol/mcp`.
- **Capability lookup = `capability-protocol`, not a parallel flag object.** Catalogues (`defcatalogue :llm` / `:world`) are **vocabulary**. Define/query is CLOS: `make-catalogue`, `register-capability`, `get-capability`, `capability-supported-p`, `catalogue-defines-p`. Interned `find-catalogue` spec is read-only — `make-catalogue` copies vocab + empty entries. `backend-supports-p` is a **wire probe** only; clients look up via `make-llm-catalogue`. No `llm-features` blob. `capability-protocol` **0.2.1**.
- **LM Studio live:** workspace-root `.env` (gitignored) holds `LM_API_TOKEN` / `OPENAI_*`. Default `http://127.0.0.1:1234/v1` — LM Link is the same URL (preferred device). **Demo runs prefer the LM Link Windows host `bakemono-lair`** (`lms link set-preferred-device <id>`, check `lms link status` / `lms ls` DEVICE column); its GPU serves the larger models (gemma-4-12b-qat, nemotron-3-nano-omni, qwen3.8-27b). Host offline → say so in the demo output, do not silently fall back to the Mac. Token prefix is `sk-lm-`. **Live embed** = [`cl-stack-llm-demo`](https://github.com/egao1980/cl-stack-llm-demo) `scripts/smoke-embed.lisp` (LM Studio `/v1/embeddings`, then llama.cpp GGUF, then vllm.cpp). GGUF embed that matches LM Studio (`bert`, `qwen3`, …) is [`llama-cpp`](https://github.com/egao1980/llama-cpp) + [`llm-backend-llama-cpp`](https://github.com/egao1980/llm-backend-llama-cpp). Darwin `vllm-cpp` 0.1.1 only loads `qwen35` / `qwen35moe` / `qwen3next` / `deepseek4` / `muse-glimmer`. Do **not** add gated `LIVE=` Rove embed tests in protocol/backend packages. **`llama-cpp` natives** publish from the owning repo (`publish-oci.yml`): linux/amd64 **CUDA+Vulkan**, windows/amd64 **CUDA+Vulkan**, linux/arm64 CPU, darwin/arm64 Metal. Independent of `vllm-cpp` (that one is linux/amd64 CUDA-only; Windows CUDA is not an upstream vllm.cpp target). Never ship `libcuda`/`nvcuda` or Vulkan ICDs.

## Blackboard

- **Blackboard core ≠ agent-wire ≠ Cursor agent infra.** [`blackboard-protocol`](https://github.com/egao1980/blackboard-protocol) **0.1.1** + colocated [`capability-protocol`](https://github.com/egao1980/blackboard-protocol) **0.2.1** (KSAR loop, COW workspaces, `requeue-ksar`, serial-per-workspace). **Zero** MCP/A2A/AG-UI/`llm-protocol` deps. Continuation is `ksar-continuation`, published in `release-ksar-slot` under the agenda lock — do not treat join-before-idle as the requeue contract. Handler death wraps as `ksar-handler-error` (`:cause`) with `continue`/`retry`; `spawn-ksar-worker` `handler-bind`s `continue` (workspace `:failed`). Caps are root-global (COW isolates sections, not instances) — concurrent workspaces share the same objects. Wire adapters and the [`egao1980/demiurge`](https://github.com/egao1980/demiurge) product (new 0.2 core replaces the legacy tree) sit above. Cursor skills/`/stack-status` are unrelated. Cookbook [`blackboard.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/blackboard.md) · briefs [`blackboard.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/blackboard.md) / [`capability.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/capability.md) ([#192](https://github.com/egao1980/cl-stack/issues/192)–[#197](https://github.com/egao1980/cl-stack/issues/197)).

## Agent-wire RPC

- **Agent-wire RPC stack = `rpc-protocol-*`:** [`mcp-protocol`](https://github.com/egao1980/mcp-protocol) / [`a2a-protocol`](https://github.com/egao1980/a2a-protocol) / [`ag-ui-protocol`](https://github.com/egao1980/ag-ui-protocol) and their backends dispatch through `rpc-protocol` GFs (`rpc-call` / `rpc-notify` / `rpc-call-stream` / `rpc-serve`). JSON-RPC wire = `rpc-protocol-json`. gRPC = `rpc-protocol-grpc` (do **not** call `grpc-protocol` from an agent-wire backend). Transports = `rpc-backend-{stdio,http,sse,inprocess}`. Protocol backends are thin adapters (headers, well-known, SSE mapping) — **do not copy** `http-rpc-transport` / a second JSON-RPC codec. AG-UI is `:call-stream` + an AG-UI codec (never a JSON-RPC envelope). A2A HTTP+JSON REST still uses rpc modes; do not grow a parallel HTTP RPC stack — extend `rpc-backend-http` / add a codec.
- **Process / RPC:** [`process-protocol`](https://github.com/egao1980/process-protocol) + [`process-backend-uiop`](https://github.com/egao1980/process-backend-uiop) **0.1.0**. [`rpc-protocol`](https://github.com/egao1980/rpc-protocol) **0.2.0** owns interaction modes (`:call-response` / `:notify` / `:call-stream` / `:client-stream` / `:bidi-stream`) — encoding-agnostic. JSON-RPC 2.0 is [`rpc-protocol-json`](https://github.com/egao1980/rpc-protocol-json) **0.1.0**. gRPC binding is [`rpc-protocol-grpc`](https://github.com/egao1980/rpc-protocol-grpc) over [`grpc-protocol`](https://github.com/egao1980/grpc-protocol) (wire/channel; backends `grpc-backend-http2` / `grpc-backend-native`). Transports: inprocess **0.1.0**, stdio/http/sse **0.1.1**. Cookbook [`rpc.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/rpc.md) · [#170](https://github.com/egao1980/cl-stack/issues/170). Do **not** wrap AG-UI in JSON-RPC — official HTTP is `:call-stream` + an AG-UI codec.
- **MCP dual-era:** [`mcp-protocol`](https://github.com/egao1980/mcp-protocol) **0.2.0** + stdio **0.1.1** + Streamable HTTP **0.2.0**. Latest two revisions only — modern **`2026-07-28`** (stateless `_meta`, `server/discover`, `resultType`, SEP-2549 `ttlMs`/`cacheScope`, no session) and legacy **`2025-11-25`** (`initialize` handshake). Do **not** treat `2025-06-18` as supported. Dual-era client prefers discover; **any** discover error other than a retryable `-32022` → `initialize` (FastMCP 3 uses `-32602`). `cl-mcp` stays a Lisp-tools product (does not become `mcp-protocol`). Interop canary: [`mcp-parity`](https://github.com/egao1980/mcp-parity) — Lisp↔FastMCP 3 / official Node SDK v2, **stdio and Streamable HTTP** both ways (sse-parity shape). HTTP client: `Mcp-Name` = tool/prompt/uri on call/get/read; echo `Mcp-Session-Id` (FastMCP 3). GET 405 is spec-ok. Cookbook [`mcp.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/mcp.md) · [#185](https://github.com/egao1980/cl-stack/issues/185).
- **lisp-mcp = three first-party layers:** [`lisp-source-protocol`](https://github.com/egao1980/lisp-source-protocol) (`stack-lisp-source`: lossless Eclector CST, never evals/interns, EOF-resync recovery + `imbalance`, package model, lint GF, structural `edit-plan` + `verify-plan`), [`repl-protocol`](https://github.com/egao1980/repl-protocol) (`stack-repl`: debugger as value, `swank-family-connection`, conformance suite) + [`repl-backend-swank`](https://github.com/egao1980/repl-backend-swank) / [`repl-backend-slynk`](https://github.com/egao1980/repl-backend-slynk) (name tables + spawn only), and [`lisp-mcp`](https://github.com/egao1980/lisp-mcp) (tools, resources and notifications over `mcp-protocol` ≥ 0.3.0). The server never evaluates project code; images are separate processes. 0.2.0 (2026-11-07) added `move-node`, a table-driven indenter fed by image hints and project macros, Slynk mrepl channels, stepping, an event listener → MCP log/resource notifications, and server-side notifications in `mcp-protocol` (backend-supplied notifier; stdio any thread, HTTP in-request SSE). Skill **lisp-mcp-tooling**; cookbook `cl-stack/docs/cookbooks/lisp-mcp.md`.
- **MCP spec surface lives in `mcp-protocol`:** every spec feature (sampling, elicitation, roots, completions, logging, progress, subscriptions/listen, resource templates, list_changed, MRTR `input_required`) MUST exist as GFs + CLOS classes in the protocol layer even if backends implement I/O later. Do not leave those as “wave-N non-goals.”
- **gRPC Windows:** do **not** vcpkg/MSVC overlay `egao1980/grpc`. Portable path is [`grpc-backend-http2`](https://github.com/egao1980/grpc-backend-http2) (unary over `http-protocol` H2; TLS only). `grpc-backend-native` stays linux/darwin C-core. `TE: trailers` allowed on H2 in `http-protocol` ≥ 0.3.1.
- **cl-protobufs Windows:** WKT Lisp vendored under `wkt/` (`2.0-rc2+`); load does not require `protoc`. Unix overlays still ship the plugin for compiling user `.proto`. No clean-room proto3 DOM.
- **SSE (agent-wire):** [`sse-protocol`](https://github.com/egao1980/sse-protocol) **0.1.0** + http/clack backends **0.1.0**. Keepalives and `io-protocol` object streams are **independent**. Keepalives = protocol-owned comment `: ping` (configurable style/interval/payload); reader skips unless `:include-keepalives`. High-level stream = `make-sse-input-stream` / `make-sse-output-stream` → `read-object` / `write-object` of `sse-event` (framing, not prin1). Do not fold keepalive timers into the object-stream wrapper. Framing compliance = Lisp-owned sexp dumps of WPT `eventsource/format-*` + rexxars/eventsource-fixtures static routes (`sse-protocol` `tests/fixtures/`). Empty `event:` is default message (do not dispatch empty-data). Interop canary: [`sse-parity`](https://github.com/egao1980/sse-parity) — Lisp↔Node (`eventsource`) / Python (`httpx-sse`) both ways. Cookbook [`sse.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/sse.md) · [#184](https://github.com/egao1980/cl-stack/issues/184).
- **A2A (agent-wire):** [`a2a-protocol`](https://github.com/egao1980/a2a-protocol) **0.2.0** (`stack-a2a`) — Agent Card + tasks. Bindings: [`a2a-backend-jsonrpc`](https://github.com/egao1980/a2a-backend-jsonrpc) **0.2.1**, [`a2a-backend-httpjson`](https://github.com/egao1980/a2a-backend-httpjson) **0.2.0**, [`a2a-backend-grpc`](https://github.com/egao1980/a2a-backend-grpc) **0.2.0** (`rpc-protocol-grpc`, path `/lf.a2a.v1.A2AService/*`; JSON payloads until official proto). Card: `/.well-known/agent-card.json` (+ `agent.json`). Canary: [`a2a-parity`](https://github.com/egao1980/a2a-parity). Cookbook [`a2a.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/a2a.md) · [#186](https://github.com/egao1980/cl-stack/issues/186).
- **AG-UI (agent-wire):** [`ag-ui-protocol`](https://github.com/egao1980/ag-ui-protocol) **0.3.1** (`stack-ag-ui`) — typed events via [`schema-protocol`](https://github.com/egao1980/schema-protocol) (`defschema`, `:tag type`, camelCase) + [`schema-protocol-json`](https://github.com/egao1980/schema-protocol-json) (draft-07 emit/`validate-ag-ui-json`, tool `parameters`). Not JSON-RPC. Default echo + `make-ag-ui-app` (Clack POST → SSE; GET → `AgentCapabilities`; `Accept` negotiates SSE vs proto). Backends: [`ag-ui-backend-sse`](https://github.com/egao1980/ag-ui-backend-sse) **0.2.1**, [`ag-ui-backend-protobuf`](https://github.com/egao1980/ag-ui-backend-protobuf) **0.3.0**. **Binary is JSON-as-WKT** (`google.protobuf.Value` via serdes `:wkt` in [`protobuf-protocol`](https://github.com/egao1980/protobuf-protocol) **0.2.0** / [`protobuf-backend-cl-protobufs`](https://github.com/egao1980/protobuf-backend-cl-protobufs) **0.2.0**), length-prefixed `application/vnd.ag-ui.event+proto` — **not** the official `Event` oneof. Interop canary: [`ag-ui-parity`](https://github.com/egao1980/ag-ui-parity) — Lisp↔`@ag-ui/*` / Python `ag-ui-protocol`, SSE JSON both ways; WKT proto Lisp-only; official Event oneof skipped. HTTP client: `http-backend-async` × libuv. Cookbook [`ag-ui.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/ag-ui.md) · [#187](https://github.com/egao1980/cl-stack/issues/187). **`:key-style` does not inherit** — every event subclass must repeat `(:key-style :camel)` or dump/parse uses kebab/`thread-id` instead of `threadId`.
