Brief [`cl-stack/docs/capabilities/sql.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/sql.md).

## IO / serdes / schema

- **html-protocol** (`stack-html`) **0.1.0:** CLOS HTML document + parse/serialize + tiny CSS select. **CSS/JS are opaque text** (`<style>` / `<script>` / `style=` / `href`/`src`) — no cascade, no JS VM.
- **io-protocol / serdes (wave-1 done):** [`io-protocol`](https://github.com/egao1980/io-protocol) (`stack-io`, OCI **0.1.0**) — ObjectInput/Output Gray shell, default `prin1`/`read`, **no serdes dep**. [`serdes-protocol`](https://github.com/egao1980/serdes-protocol) **0.2.1** / [`sexp-protocol`](https://github.com/egao1980/serdes-protocol) **0.2.0** — whole-value + Gray/JSONL/event GFs; [`json-protocol`](https://github.com/egao1980/json-protocol) **0.2.0** hard-implements `:json` (JSONL + jzon `parse-next`); [`toml-protocol`](https://github.com/egao1980/toml-protocol) **0.1.0** + `toml-backend-tomlet` implements `:toml` (datetime-protocol mapping); [`compression-protocol`](https://github.com/egao1980/compression-protocol) **0.1.1** + `compression-backend-chipz` — gzip/zlib/deflate + ZIP; `:br`/`:zstd`/`:snappy` via overlay EQL methods; [`csv-protocol`](https://github.com/egao1980/csv-protocol) **0.1.0** (`stack-csv`) implements `:csv` / `:tsv`; [`xml-protocol`](https://github.com/egao1980/xml-protocol) **0.1.0** (`stack-xml`) well-formed XML 1.0 + NS Infoset / pull events / writer + `xml-backend-native` (XXE-safe). `:xml` serdes is well-formed only. **Arrow/Parquet:** [`arrow-protocol`](https://github.com/egao1980/arrow-protocol) (`stack-arrow`) OCI **0.1.0** — native IPC + Parquet (not CFFI); serdes `:arrow` / `:parquet`. **Protobuf:** [`protobuf-protocol`](https://github.com/egao1980/protobuf-protocol) **0.2.0** implements `:protobuf`. **RFC 4648 / CTE / RLE:** [`encoding-protocol`](https://github.com/egao1980/encoding-protocol) **0.1.2** — see Unicode / MIME / IDNA below. Frozen pyarrow fixtures, no Python in CI. Briefs [`io.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/io.md) / [`serdes.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/serdes.md) / [`arrow.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/arrow.md) / [`csv-protocol.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/csv-protocol.md) / [`encoding-protocol.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/encoding-protocol.md).
- **schema-protocol (wave-1):** [`egao1980/schema-protocol`](https://github.com/egao1980/schema-protocol) (`stack-schema`) **0.2.0** (`emit-schema` / `parse-schema`) — CLOS interchange models (`schema-class` + `defschema`), Lisp type specifiers, nested/computed/validators, **`:tag` discriminated unions** (subclasses), **`defenum`** (proto aliases: name / `TYPE_MEMBER` / number / `allow_alias`). **Not** pydantic API; **not** `sql-orm` `defmodel`. Coercion opt-in (`:coerce t`). JSON null = `:null`. Wire via serdes (`:format`) when loaded. Format implementors (separate repos): [`schema-protocol-json`](https://github.com/egao1980/schema-protocol-json) (`stack-schema-json`) draft-07 emit/parse/compile + OpenAPI `discriminator`; [`schema-protocol-xsd`](https://github.com/egao1980/schema-protocol-xsd) (`stack-schema-xsd`) **0.1.3** XSD 1.0/1.1 — trees are `xml-protocol` `xml-element` (`xml-elem` deleted); `decode-validating` = decode then `validate-instance`. Streaming XSD validator later. [`schema-protocol-arrow`](https://github.com/egao1980/schema-protocol-arrow) (`stack-schema-arrow`) OCI **0.1.0** — `arrow-schema` GF + `table-from-objects`. Avro emit/parse lives in [`avro-protocol`](https://github.com/egao1980/avro-protocol) (`schema-protocol-avro`). Interop canary: workspace-local [`schema-parity`](../schema-parity) — Lisp emit → Python (jsonschema / xmlschema / fastavro / pyarrow) + JS (Ajv / avsc / apache-arrow) accept/re-emit → Lisp `parse-schema`. CI-only, not GHCR. `json-schema` / `xsd-schema` / `arrow-schema` / `avro-schema` GFs live on the protocol; methods in the format package. Ignore leftover empty [`json-schema-protocol`](https://github.com/egao1980/json-schema-protocol) (misnamed). **OpenAPI (P2 #2) shipped 0.1.0:** [`openapi-protocol`](https://github.com/egao1980/openapi-protocol) (`stack-openapi`) — emit + Clack `document-app`. Dogfood `schema-protocol-json` + `json-protocol`/`yaml-protocol`. YAML **extends** JSON (`yaml-backend` ⊆ `json-backend`, same repo). Do **not** invert (json must not depend on yaml). No second schema dialect, YAML parser, or CLOS model layer.

## Unicode / MIME / IDNA

- **Unicode / i18n / l10n split (ICU-shaped):** [`unicode-protocol`](https://github.com/egao1980/unicode-protocol) (`stack-unicode`) **0.1.2** (+ `unicode-protocol/conformance`). Backends: [`unicode-backend-cl-unicode`](https://github.com/egao1980/unicode-backend-cl-unicode) **0.1.0** (default portable); [`unicode-backend-sbcl`](https://github.com/egao1980/unicode-backend-sbcl) **0.1.0** (`sb-unicode`, no `:idna`); [`unicode-backend-icu`](https://github.com/egao1980/unicode-backend-icu) **0.1.1** + [`cl-stack-icu`](https://github.com/egao1980/cl-stack-icu) **78.1.3** (linux/darwin/**windows** overlays; label IDNA + Script_Extensions; auto-load on ASDF load); [`unicode-backend-icu4j`](https://github.com/egao1980/unicode-backend-icu4j) **0.1.2** + [`cl-stack-icu4j`](https://github.com/egao1980/cl-stack-icu4j) **78.1.3** (ABCL auto-bind). IDNA facade [`cl-stack-idna`](https://github.com/egao1980/cl-stack-idna) — **do not** mutate Ultralisp [`egao1980/cl-idna`](https://github.com/egao1980/cl-idna). [`i18n-protocol`](https://github.com/egao1980/i18n-protocol) / [`l10n-protocol`](https://github.com/egao1980/l10n-protocol) + ICU/ICU4J backends **0.1.1** / **0.1.2** (Accept-Language q-weights; `:skeleton` formatters; ICU4J auto-bind on ABCL). Leftovers [#176](https://github.com/egao1980/cl-stack/issues/176)–[#178](https://github.com/egao1980/cl-stack/issues/178) closed. Babel = octets↔string only. Cookbook [`cl-stack/docs/cookbooks/unicode.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/unicode.md); briefs `cl-stack/docs/capabilities/{unicode-protocol,i18n,l10n,text-unicode}.md`.
- **MIME:** [`mime-protocol`](https://github.com/egao1980/mime-protocol) **0.1.0** (`stack-mime`) — parse/print + multipart; serdes `:mime` / `:multipart`. CTE bytes go through [`encoding-protocol`](https://github.com/egao1980/encoding-protocol). `cl-mime` **0.5.1** pin is an escape hatch, not the DX. **Not** HTTP `Content-Encoding` (gzip/br/zstd/snappy).
- **Encodings:** [`encoding-protocol`](https://github.com/egao1980/encoding-protocol) **0.1.2** (`stack-encoding`) — RFC 4648 / QP / classic RLE. Core = Babel only; `encoding-protocol/serdes` registers `:base64` `:base64url` `:base32` `:base32hex` `:base16` `:quoted-printable` `:rle`. Replaces `cl-base64` in first-party (http / ws / mime / secrets / jwt / oauth2 / arrow / http-parity). URI percent-encoding stays in quri. Parquet hybrid RLE stays in arrow-protocol.
- **IDNA / URI pins:** [`egao1980/cl-idna`](https://github.com/egao1980/cl-idna) (IDNA2008 / UTS #46) — not `antifuchs/idna`. OCI: `ghcr.io/egao1980/cl-systems/cl-idna:0.1.0`. Fork [`egao1980/quri`](https://github.com/egao1980/quri) `0.7.1` → `cl-idna:to-ascii`; OCI `ghcr.io/egao1980/cl-systems/quri:0.7.1`. **No upstream PR to fukamachi/quri** until `cl-idna` is on Quicklisp.
