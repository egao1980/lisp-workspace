# HTTP / WS / encodings

## Design

- **HTTP version design:** RFCs first (7301 ALPN, 9113 H2). CLOS split — **http-protocol** owns preference (`:auto`/`:http/1.1`/`:http/2`), ALPN offer/map, H2 header-field policy (`make-http2-request-headers`), `backend-http-versions`; **backends** own TLS ALPN, framing/HPACK (or OS H2), `response-http-version`. No framing in protocol; no ad-hoc Host/Connection on H2 wire.
- **http-protocol:** [`egao1980/http-protocol`](https://github.com/egao1980/http-protocol) — **urllib3/httpx layer** (not requests). Transport policy in protocol: `http-timeout`, `http-retry`, `http-proxy-config` (dexador#202 shape), `http-connection-pool` / `pooled-body-stream`. Wire bodies = streams/octets/strings/`http-file` only — **no FS**. Sync path = await on async engine (dexador = maintenance). Async: [`http-backend-async`](https://github.com/egao1980/http-backend-async) × libuv/libev; usocket; cl-stack-ssl WANT_*; `sleep* 0` next-tick. Live CE: `HTTP_ASYNC_LIVE=1`. Windows proxy auth / AUTOMATIC / NTLM SSO: [`http-backend-winhttp`](https://github.com/egao1980/http-backend-winhttp) (`WINHTTP_FLAG_ASYNC`, Gray streams, cancel); CI = cl-repo only (`windows-latest` + ubuntu stubs).
- **cl-stack-http:** [`egao1980/cl-stack-http`](https://github.com/egao1980/cl-stack-http) (nick `stack-http`) — **requests-like** layer over `http-protocol`: JSON (yason) + `:sexp` serdes, pathlib upload/download, Session, Digest/netrc, CLOS auth protocol + request hooks. OCI **0.1.8**. Typical pins: `http-protocol:0.3.4`, `cl-stack-pathlib:0.2.1`, backends async **0.2.5** / dexador **0.1.2** / winhttp **0.1.3**.
- **HTTP Content-Encoding:** gzip/deflate (**chipz**/**salza2**) + **br** + **zstd** + **snappy** (raw). Overlays: [`cl-stack-brotli`](https://github.com/egao1980/cl-stack-brotli) Brotli **v1.2.0** → `ghcr.io/egao1980/cl-systems/cl-stack-brotli:1.2.0`; [`cl-stack-zstd`](https://github.com/egao1980/cl-stack-zstd) Zstd **v1.5.7** → `ghcr.io/egao1980/cl-systems/cl-stack-zstd:1.5.7`; [`cl-stack-snappy`](https://github.com/egao1980/cl-stack-snappy) Snappy **1.2.2** + [`http-encoding-snappy`](https://github.com/egao1980/http-encoding-snappy) (linux/amd64+arm64, darwin/arm64, windows/amd64). Brief: `cl-stack/docs/capabilities/http-protocol.md`.
- **ws-protocol:** [`egao1980/ws-protocol`](https://github.com/egao1980/ws-protocol) — wave-1 **done**; **0.2.2** = CLOS `:transport` + `feature-or-env-enabled-p`. Product H1 driver is [`ws-backend-websocket-driver`](https://github.com/egao1980/ws-backend-websocket-driver) (own repo; demo `scripts/demo.lisp`). **winhttp 0.1.3** = H1 WS (`WINHTTP_WS_LIVE`). **async 0.2.4** = loop-native Extended CONNECT + `scripts/demo-ws.lisp`. Cookbook: `cl-stack/docs/cookbooks/websocket.md`.
- **http-server-protocol:** [`egao1980/http-server-protocol`](https://github.com/egao1980/http-server-protocol) — wave-2 **done** (#93); OCI **0.1.0**. Clack env app contract; default `http-server-backend-hunchentoot` (Windows+); Unix second `http-server-backend-woo` (`use-woo-backend`, needs libev). Nick `stack-http-server`. Cookbook: `cl-stack/docs/cookbooks/http-server.md`. Publish: blank `PKG_VERSION` from workflow_dispatch is truthy — treat empty string as missing.

## Canary / cookbook

- **http-parity:** [`egao1980/http-parity`](https://github.com/egao1980/http-parity) — demo/CI canary for cl-stack-http vs requests/httpx. Default origin = local httpbin fixture (`HTTP_PARITY_FIXTURE=1`); prefer `:async` + libuv. Public httpbingo often 402s async TLS at Fly edge. Realistic app: `ros -l scripts/demo.lisp` (login → JSON catalog → download). Live CE+CD: `ros -l scripts/finance-demo.lisp` (Frankfurter + Fin-node; `HTTP_PARITY_FINANCE=1` for Rove). CI: thin `ensure-system-dependencies` + client **`latest`** (anchor resolve); pins resolve from GHCR (expect `http-protocol:0.3.4`, `cl-stack-http:0.1.8`, `http-backend-async:0.2.5`).
- **Cookbook:** [`cl-stack/docs/cookbooks/http-client.md`](https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/http-client.md) — requests/httpx → stack-http (§13 timing/byte stats).
